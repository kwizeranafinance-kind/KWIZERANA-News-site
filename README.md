# KWIZERANA News Site

Daily KWIZERANA Intelligence newsletter dashboard.

## Structure

- `index.html` is the latest published dashboard.
- `reports/YYYY-MM-DD/index.html` stores each daily archive.
- `brand/` contains approved Kwizerana logo assets derived from `kwizeranalogo A.pdf`.

## Daily Update

1. Create a new folder under `reports/` using the report date.
2. Copy the latest dashboard into that folder.
3. Update `index.html` with the newest dashboard.
4. Commit and push.
